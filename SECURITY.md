# Security Policy

This repository holds the source of vrdlib.com. Report a vulnerability
in the website, or in the vrd library it describes, privately by the
email address in the library's
[security policy](https://github.com/sebastienrousseau/vrd/security/policy)
or through
[GitHub's advisory form](https://github.com/sebastienrousseau/vrd/security/advisories/new).
Machine-readable disclosure metadata lives at
[`/.well-known/security.txt`](.well-known/security.txt) per
[RFC 9116](https://www.rfc-editor.org/rfc/rfc9116).

Please do **not** open a public GitHub issue for a suspected security
vulnerability: report it privately first to coordinate disclosure.
